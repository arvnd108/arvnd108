### 🌧️ WEAVR
**Multi-model rainfall forecast blending for India**
<sub>Research prototype · Smart India Hackathon 2026 · PS 26081</sub>

- Blends **GraphCast, ECMWF HRES and IFS-ensemble** monsoon forecasts on a 0.25° India grid (24-96 h leads)
- Region- and lead-specific weights, with probabilities at IMD warning thresholds via **EMOS/BMA** tiers
- Verified against IMD gauge analyses: leave-one-year-out, block bootstrap, Diebold-Mariano tests and **pre-registered hypotheses**
- Reports negative results too: a GPD tail splice removed all 193 false-zero cells but lowered SEDI

`Python` `NumPy` `SciPy` `xarray` `Zarr` `FastAPI` `JavaScript`

### 🧬 Athena
**Oncology clinical decision support**
<sub>Engine behind SecondLook · Smart India Hackathon 2026 · PS 26198</sub>

`Python 3.11` `FastAPI` `SQLAlchemy` `FalkorDB` `Anthropic API` `MCP` `GitHub Actions`

### 🔐 EVOCK
**Tamper-evident evidence preservation for online abuse**
<sub>Chromium extension · 🏅 Yantrika 1.0 Finalist</sub>

- Captures the visible browser state; a vision-language model extracts visible content into metadata **labelled as AI output, not ground truth**
- Preservation still completes if extraction is unavailable
- Seals each record with **SHA-256** hashes, a per-vault **ECDSA P-256** signature and **AES-GCM** encryption in an IndexedDB vault
- A local proxy keeps the API key out of the extension

`JavaScript` `Chromium Extension` `IndexedDB` `jsPDF` `JSZip`

[![GitHub](https://img.shields.io/badge/Code-181717?style=flat-square&logo=github)](https://github.com/arvnd108/EVOCK) [![Demo](https://img.shields.io/badge/Live_Demo-00d2ff?style=flat-square&logo=vercel&logoColor=white)](https://evock-marketing-website.vercel.app)
